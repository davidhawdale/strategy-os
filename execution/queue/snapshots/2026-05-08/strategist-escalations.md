## Escalation 3 (NEW): Brand architecture — separate Borders brand vs Borders section/topic within an existing P&J or Courier subscription

**What is at stake:** The new T1 evidence on DCT's observed practice in dispersed Scottish geographies (Elgin/Moray c.95k pop, Inverness c.50-85k, Oban & Hebrides c.50k dispersed) shows that DCT serves these geographies with *free local newsletters inside the regional title's editorial scope*, not with separate paid titles. The Borders (c.117k) sits at or just above this newsletter threshold and below the c.260k+ population that supports the full P&J subscription. The v1 register defaulted to a separate Borders brand ("The Borders Journal" working title) without considering the alternative observed configuration. The CHALLENGE pass makes that alternative legible. This is a values/strategic decision the strategist cannot make.

**The two configurations:**

| Configuration | What it is | Pros | Cons |
|---|---|---|---|
| (A) Separate Borders brand | New masthead, own subscription product, own domain, own app or own brand within shared app | Clear brand identity; reuses competitor-vacated naming space; potential for diaspora expansion in Phase 3; consistent with v1 register | Higher fixed cost (brand, identity, possibly own Pugpig instance — see E-01); requires own audience-acquisition rather than leveraging existing P&J/Courier base; tested by no observable DCT precedent in this size band |
| (B) Borders section within existing brand (P&J or Courier extension) | "Borders" added as a 10th geographic locale on the existing P&J app/website (or as a new section under Courier); free Borders newsletter inside the existing brand; possibly a Borders-specific upsell tier within existing subscription | Consistent with DCT's observed pattern in Moray/Inverness/Oban; near-zero marginal infrastructure cost (multi-locale capability already operational per pj-app-onboarding-4.PNG); leverages existing P&J/Courier subscriber base for cross-sell; lower-risk first commitment | Less clear Borders brand identity; ambiguous which existing brand (P&J = North/Highlands; Courier = Tayside/Fife) is geographically/identity-natural for the Borders; cannibalisation risk if Borders content dilutes the existing brand's editorial focus; harder to distinguish "Borders coverage" as a paid upsell when existing subs already get it |
| (C) Hybrid sequenced approach | Phase 0 = Borders newsletter inside existing P&J or Courier brand (config B-equivalent); Phase 1 paid product = separate Borders brand if Phase 0 demand validates (config A); decision deferred until behavioural data exists | Defers the most expensive commitment until data is in hand; uses Phase 0 to test whether Borders demand is brand-distinguishable or brand-fungible; consistent with the "compression model" (do not commit until alternatives can be eliminated by evidence) | Carries operational complexity of running a Borders section within an existing brand for 3-6 months then potentially migrating; risks confusing audience if the brand changes mid-stream |

**Question for governor:** Which configuration does DCT want to commit to, or does DCT want the strategist to recommend (C) — sequence the Phase 0 newsletter within an existing brand and defer the brand-architecture decision until behavioural data is in hand?

This question depends on values that are not for the strategist to decide:
- DCT's tolerance for a less distinctive Borders brand vs the operational simplicity of section-within-existing-brand
- Long-run portfolio strategy (does DCT want the optionality of a third regional brand, or is the strategic intent to deepen the existing two brands' geographic coverage?)
- View on cannibalisation between P&J/Courier subscribers and a hypothetical Borders subscription
- Editorial identity question: does Borders coverage feel naturally like a P&J extension (geographic continuity to the south) or a Courier extension (cultural / Fife-Tayside continuity)?

**If the answer is (A) — separate brand:** The v1 register holds substantially. E-01 (separate-brand platform marginal cost) remains the load-bearing escalation; the unit economics base case still works at the revised ARPU.

**If the answer is (B) — section within existing brand:** Sections 3, 4, 5, 6, 7 require material revision. Unit economics shift from a standalone P&L to a contribution analysis on the existing brand; pricing reverts to existing P&J or Courier tiers; VP differentiator becomes "expanded coverage from your existing trusted Scottish title" rather than "new daily Borders product"; the existing escalation E-02 (overhead allocation) loses force because there is no separate P&L. This pathway is materially cheaper and lower-risk but also ceiling-bound (it cannot become a standalone unit later without a brand split).

**If the answer is (C) — sequenced/deferred:** The CHALLENGE-revised register holds (Phase 0 newsletter inside existing brand; Phase 1 brand-architecture decision pending Phase 0 data). This is the strategist's recommended path *if* the values question is genuinely open, because it preserves the most optionality for the lowest committed spend. But (C) is itself a values choice (deferral of brand commitment), not a default.

**Decision needed by:** before Phase 0 commences (so c.2026-06-15 if Phase 0 budget is approved on the timeline implied by Esc-3).

## Escalations 1 and 2 — status update

**Escalation 1 (Platform marginal cost):** Partially addressed by 2026-05-05 T1 evidence. Specifically, the live P&J app's multi-locale follow capability (research/press-and-journal/pj-app-onboarding-4.PNG showing 9 geographic topics selectable) provides T1 evidence that **adding a new geographic locale within an existing brand is operationally supported by the platform**. This resolves the assumption for *configuration (B)* in Escalation 3 above. It does NOT resolve the assumption for *configuration (A)* — standing up a separate Borders brand — because that involves separate masthead, identity, possibly separate Pugpig deployment, separate subscription product, etc. Escalation 1 should be re-scoped to specifically address the separate-brand pathway: **What is the marginal cost of a third *brand* (not a third *locale*) on DCT's existing platform stack?**

**Escalation 2 (Overhead allocation):** Unchanged. Still load-bearing on the unit economics for configuration (A). Loses force entirely under configuration (B). The answer to Escalation 3 (the brand-architecture decision) determines whether Escalation 2 remains relevant.
