# Dashboard Term Help

This file contains presentation-layer help text for the dashboard. Canonical StrategistOS doctrine remains in `CLAUDE.md`, `STANDARDS.md`, and the templates.

| Key | Term | Dashboard Label | Help Text | Canonical Source |
| --- | --- | --- | --- | --- |
| evidence | Evidence |  | Signals used to support or challenge a hypothesis claim. | STANDARDS.md — Evidence Entry Format |
| research-sources | Research Sources |  | The sources behind the evidence, such as articles, data, reports, references, or local files. | templates/hypotheses.md — Research Sources |
| assumptions | Assumptions | Assumptions | Things that must be true for the hypothesis or strategy to work. | STANDARDS.md — Assumptions Format |
| research-unlocks | Research Unlocks |  | Research actions that would reduce uncertainty or move weak claims toward stronger evidence. | strategy/gap-analysis.md — Recommended Action and Evidence Target |
| t1 | T1 |  | Public, direct, or ground-truth evidence. | CLAUDE.md — Evidence Tiers; STANDARDS.md — Evidence Quality Scoring |
| t2 | T2 |  | Synthesised reasoning or research evidence. | CLAUDE.md — Evidence Tiers; STANDARDS.md — Evidence Quality Scoring |
| t3 | T3 |  | A claim that still requires real-world validation. | CLAUDE.md — Evidence Tiers; STANDARDS.md — Evidence Quality Scoring |
| load-bearing | Load-Bearing |  | An assumption whose failure could cause the hypothesis to collapse. | STANDARDS.md — Assumptions Format |
| blast-radius | Blast Radius |  | How much damage an assumption causes if it turns out false. | STANDARDS.md — Assumptions Format |
| belief | Belief |  | A claim the strategy currently depends on but has not fully proven. | STANDARDS.md — Assumptions Format |
| knowledge | Knowledge |  | A claim treated as known from available evidence. | STANDARDS.md — Assumptions Format |
| observation | Observation |  | A directly observed signal or condition. | STANDARDS.md — Assumptions Format |
